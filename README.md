# 🔐 Cloud-Based SIEM Analytics and Automated Incident Response

## 📖 Overview

This project demonstrates a Cloud-Based Security Information and Event Management (SIEM) system developed using Python and Sumo Logic.

The system simulates multiple cyber attacks, enriches security logs using Threat Intelligence, GeoIP, and MITRE ATT&CK mapping, assigns risk scores, visualizes security events through dashboards, and automates incident response.



## 🚀 Features

- Security Log Generation
- Threat Intelligence Enrichment
- GeoIP Lookup
- MITRE ATT&CK Mapping
- Risk Score Calculation
- IOC Detection
- Dashboard Visualization
- Automated Incident Reports
- Executive SOC Report
- Email Alerting


## 🛠 Technologies Used

- Python
- Google Colab
- Sumo Logic Cloud SIEM
- MITRE ATT&CK Framework
- Threat Intelligence
- GeoIP
- Pandas
- Requests



## 📊 Dashboards

The project includes dashboards for:

- Total Security Events
- Critical Threats
- Attack Severity
- Attack Distribution
- MITRE ATT&CK Mapping
- IOC Summary
- Threat Intelligence
- Executive SOC Report
